# Coal Mine Equipment Fault & Maintenance Management System

## 📌 Project Overview

The **Coal Mine Equipment Fault & Maintenance Management System** is a web-based application developed to help manage coal mine equipment, identify equipment faults, and maintain maintenance records efficiently.

The system provides a centralized platform for monitoring equipment status, reporting faults, managing maintenance activities, and improving the overall maintenance management process.

This project was developed during my internship at **Central Coalfields Limited (CCL)**.

---

## 🚀 Features

* Equipment management
* Equipment fault reporting
* Maintenance record management
* User authentication
* Dashboard for monitoring equipment information
* Fault tracking and management
* Maintenance scheduling and records
* Centralized management of equipment data

## ⚙️ Installation and Setup

### Clone the repository

```bash
git clone <repository-url>
```

### Install Frontend Dependencies

```bash
cd frontend
npm install
npm run dev
```

### Install Backend Dependencies

```bash
cd backend
npm install
npm start
```
